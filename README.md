# folder-encryptor

**Recursively encrypts the given path and also encrypts the name of file and folders. Best to hide sensitive data**

![Alt text](/images/GUI.jpg  "GUI")

<h1>Warning: Use with CAUTION, do NOT lose your key.k file</h1>

**Features**

 - Uses Fernet encryption algorithm to create encryption
 - Simple User Interface
 - "Rename Only" checkbox to hide the files temporarily**.
 - Logs folder to track the progress of files and keep history 
 - Windows quick install files at - [Releases/latest](https://github.com/smandal047/folder-encryptor/releases/latest)

**For feature addition or bug please raise an issue !**

**Note: "Rename Only" just renames the file, the integrity of file still remains i.e., it can still be open via appropriate program.
